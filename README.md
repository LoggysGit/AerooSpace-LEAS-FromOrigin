# Launch Environment Analysis System (LEAS) "FromOrigin" - OpenSource MVP

**FromOrigin** - специализированное программное обеспечение для оперативного анализа пусковых условий. Система создана для того, чтобы помочь малым космическим стартапам и университетским командам принимать обоснованные решения о пуске, объединяя метеорологию, геодезию и космический мониторинг в одном интерфейсе.

> **Статус проекта:** MVP. Разработано в рамках конкурса Daryn AERO SPACE AI.

## Основные возможности

* **Комплексный сбор данных:** Автоматический опрос API баз данных.
* **Разнородность источников данных:** Интеграция мультимодальных потоков информации - от телеметрии космических объектов до геодезических параметров местности, метеорологических условий и космической погоды.
* **Индекс LCS (Launch Capability Score):** Собственный алгоритм весовых коэффициентов, который превращает тонны сырых данных в понятный балл готовности к пуску.
* **Итоговый вердикт:** Использование ИИ-моделей для интерпретации рисков и выдачи текстовых рекомендаций.

## Технологический стек MVP

* **Ядро:** Python 3.10+
* **Интерфейс (UI/UX):** PySide6 (Qt for Python)
* **Модель LLM:** Qwen2.5 7B Instruct Q4
* **API:** Открытые источники данных (OpenStreetMeteo, NASA, WAQI, etc.)

## Балл оценки LCS

**LCS** - показатель пригодности условий для запуска. Система агрегирует данные, взвешивает их по значимости и проверяет на критические "красные линии".

**Формула:**

$$LCS = (0.35 \cdot S_1 + 0.25 \cdot S_2 + 0.15 \cdot S_3 + 0.15 \cdot S_4 + 0.1 \cdot S_5) \cdot R_1 \cdot R_2 \cdot R_3$$

### 1. $S_1$: Метеорологический фундамент

Оценивает стабильность приземного слоя и риски обледенения.

$$S_1 = [100 - \frac{|1013.25 - P|}{2}] \cdot 0.4 + [\min(100, \frac{V}{100})] \cdot 0.3 + [(100 \cdot (1 - \frac{C}{100})) \cdot (1 - 0.5 \cdot (I_{T < -10} + I_{H > 0.7}))] \cdot 0.3$$

Приоритет давления ($P$), нормализация видимости ($V$) и штраф за риск льда при низкой температуре ($T$) и высокой влажности ($H$).
    

### 2. $S_2$: Динамика воздушных масс

Анализ ветровых нагрузок и качества воздуха.

$$S_2 = (33 - W_{max}) \cdot 3 - \sum |(0.705 - \cos(\Delta\theta)) \cdot W_{avg} \cdot (\Delta\theta > 45^\circ)| - \frac{AQI}{15}$$

Резкое падение балла при приближении ветра к 33 м/с и учет сдвига слоев ветра через косинус разности углов ($\Delta\theta$).
    

### 3. $S_3$: Космическая атмосфера

Радиационная защита и безопасность на орбите.

$$S_3 = (100 \cdot e^{-0.15 \cdot KP}) - Xray - (Debris \cdot 2) - |MagBias|$$

Экспоненциальная зависимость от геомагнитного индекса ($KP$) — после 4-5 баллов надежность связи падает лавинообразно.
    

### 4. $S_4$: Геодезический коэффициент

Энергетическая выгода и стабильность площадки.

$$S_4 = 100 \cdot \cos(\phi_{rad}) + \frac{H_{msl}}{500} - (20 \cdot \max(0, \alpha - 2^\circ))$$

Бонус за близость к экватору ($\phi$) и высоту ($H$), штраф за уклон поверхности ($\alpha$) более 2 градусов. _Штраф за уклон поверхности автоматически исключается для сертифицированных космодромов_
    

### 5. $S_5$: Инфраструктурный фильтр

Сложность очистки воздушного коридора.

$$S_5 = 1 - e^{-0.1 \cdot Flights}$$

Чем больше авиарейсов в зоне пуска, тем выше нагрузка на службы координации. _Автоматически исключается для сертифицированных космодромов._
    
    
###  Критические триггеры
Если нарушено хотя бы одно условие, **LCS мгновенно обнуляется** :

-   **$R_1$ (Ветер):** $W_{max} < 30 \text{ m/s}$
    
-   **$R_2$ (Геомагнитная активность):** $KP < 7$
    
-   **$R_3$ (Видимость):** $V > 4000 \text{ m}$


## Установка и запуск

Проект поставляется в виде скомпилированного исполняемого файла для Windows (.exe). Для Linux запуск происходит через открытый код.

### Системные требования
Для стабильной работы программного обеспечения необходимы характеристики, указанные ниже.

**Минимальные характеристики:**
- ОС: Windows 10/11 (64-bit) / Linux (Kernel 5.4+).
- Процессор: Intel Core i3 или AMD Ryzen 3.
- Оперативная память: 8 ГБ RAM (с учетом использования файла подкачки).
- Видеокарта: Любая с поддержкой DirectX 11 (включая интегрированные решения Intel HD/UHD Graphics).
- Место на диске: 6 ГБ.

**Рекомендуемые характеристики:**
- ОС: Windows 10/11 (64-bit) / Linux (новейшие дистрибутивы).
- Процссор: Intel Core i5 / AMD Ryzen 5 и выше.
- Оперативная память: 16 ГБ RAM.
- Видеокарта: NVIDIA GeForce GTX 1060 и выше (от 6 ГБ VRAM).
- Накопитель: SSD (для ускоренной загрузки весов модели).

Для корректной работы графического интерфейса и ускорения вычислений рекомендуется использовать актуальные версии драйверов вашей видеокарты.

### Запуск:
1. Скачайте последнюю версию с [Google Диска](https://drive.google.com/drive/folders/1F5fepoLxNbWbKoPh6bayq37d2gfjqAmT?usp=sharing).
2. Запустите исполняемый файл.
3. Дождитесь завершения загрузки модели.
4. Введите требуемые реквизиты в окно настроек.
5. Убедитесь, что у вас есть доступ к интернету для связи с API.

### Для разработчиков:
Если вы хотите запустить проект из исходного кода:
```bash
git clone https://github.com/LoggysGit/AerooSpace-LEAS-FromOrigin
pip install -r requirements.txt
python app.py
```

## Конфигурация

Для работы всех модулей необходимо ввести в окно настроек ваши API-ключи:

-   `SPACETRACK_LOGIN` / `SPACETRACK_PASSW` - учетные данные [Space-Track](https://www.space-track.org/) для мониторинга орбитального мусора и анализа безопасности околоземного пространства.
-   `NASA_API_KEY` - ваш ключ доступа к [NASA API](https://api.nasa.gov/) для получения данных о солнечной активности, рентгеновском излучении и текущем состоянии магнитосферы.
-   `WAQI_TOKEN` - токен [WAQI API](https://aqicn.org/api/) для мониторинга индекса качества воздуха (AQI).
-   `AVWX_TOKEN` - ключ доступа к [AVWX](https://info.avwx.rest/) для получения информации об авиационной деятельности.    

## Дисклеймер

Система LEAS "FromOrigin" является **инструментом поддержки принятия решений (DSS)**. Она предоставляет аналитический прогноз, основанный на открытых данных. Финальное решение о пуске и ответственность за его результаты лежат исключительно на операторе миссии.
