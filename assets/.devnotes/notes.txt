=== ПИТЧ-ТЕКСТ ===

Проблема: В наше время космос стал субъектом активного исследования. Новейшие технологии дали возможность каждому внести вклад в развитие космических технологий, а инди-командам - отправлять спутники своей разработки. К сожалению, космос - сфера рисков. Площадка запуска может не подходить, погода уменьшать зону видимости, а обьекты на околоземной орбите - повредить запускаемый аппарат и сорвать миссию, что может стоить маленьким командам миллионы долларов. А собирать данные для конкретной точки с разных источников очень сложно, дорого и занимает много времени на обьединение в единую картину.

Launch Environment Analysis System (LEAS) "FromOrigin" - программная платформа для комплексного анализа местности и условий запуска космических аппаратов, основанная на реальных данных и исскуственном интеллекте. Для получения актуальной информации система использует концепцию BYOK, что обеспечивает гибкость, удобство и безопасность для конечного пользователя.

Цель - оптимизация планирования запуска космических аппаратов, снижение риска и потенциальных экономических потерь.

Целевая аудитория:
    - образовательные и исследовательские учреждения
    - аэрокосмические стартапы и инжинерные команды
    - команды энтузиастов и независимых разработчиков космических технологий

 = DEFINES: = 
Pconst = 1013.25hPa, Tconst = 15°C
cloud_cover - COEFFICENT 0-1 (NOT PERCENTAGE 0-100!)
true = int(1), false = int(0)
xray_flux: C=int(5), M=int(30), X=int(80)
IF(Si < 0) Si = 0
latitude IN RADIANS

FORMULA:
LCS = (0.35*S1 + 0.25*S2 + 0.15*S3 + 0.15*S4 + 0.1*S5) * R1 * R2 * R3

S1 = [100 - (|1013.25 - pressure_surface| / 2)] * 0.4 + 
  [min(100, visibility / 100)] * 0.3 + 
  [(100 * (1 - cloud_cover)) * (1 - 0.5 * [(min(winds.temperature) < -10) + (average_humidity > 70)])] * 0.3
  ОБЬЯСНЕНИЕ: 
S2 = max[0, 33 - (max(winds.speed))] * 3
  ОБЬЯСНЕНИЕ: 
S3 = [100 * e^{-0.15 * Kp}] - Xray
  ОБЬЯСНЕНИЕ: 
S4 = 100 * cos(latitude) + [height_msl / 500] - [20 * slope_degree]
  ОБЬЯСНЕНИЕ: 
S5 = max(0, 100 - 50 * count(shedules))
  ОБЬЯСНЕНИЕ: 

R1 = (max(winds.speed)) < 30
R2 = kp_index < 7
R3 = visibility > 5000
