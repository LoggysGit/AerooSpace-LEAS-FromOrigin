=== ПИТЧ-ТЕКСТ ===

Проблема: В наше время космос стал субъектом активного исследования. Новейшие технологии дали возможность каждому внести вклад в развитие космических технологий, а инди-командам - отправлять спутники своей разработки. К сожалению, космос - сфера рисков. Площадка запуска может не подходить, погода уменьшать зону видимости, а обьекты на околоземной орбите - повредить запускаемый аппарат и сорвать миссию, что может стоить маленьким командам миллионы долларов. А собирать данные для конкретной точки с разных источников очень сложно, дорого и занимает много времени на обьединение в единую картину.

Launch Environment Analysis System (LEAS) "FromOrigin" - программная платформа для комплексного анализа местности и условий запуска космических аппаратов, основанная на реальных данных и исскуственном интеллекте. Для получения актуальной информации система использует концепцию BYOK, что обеспечивает гибкость, удобство и безопасность для конечного пользователя.

Цель - оптимизация планирования запуска космических аппаратов, снижение риска и потенциальных экономических потерь.

Целевая аудитория:
    - образовательные и исследовательские учреждения
    - аэрокосмические стартапы и инжинерные команды
    - команды энтузиастов и независимых разработчиков космических технологий

Возможности нашего ПО:
* Актуальная информация с официальных API
* Минималистичный, но понятный интерфейс
* Концепция BYOK, обеспечивающая безопасность и удобство для пользователя
* Легкая, но функциональная модель нейросети - Qwen 2.5 Instruct
* Чщательно прописанная роль искусственного интеллекта
* Комплексный, детализированный анализ на основе широкого объема данных

Монетизация проекта
Основной моделью монетизации LEAS "FromOrigin" является лицензирование программного обеспечения. Учреждения, желающие получить ПО приобретают единовременную лицензию на использование системы с подписанием договора о сохранении интеллектуальной собственности.

Потенциальные вектора будущего развития:
    - Обучение собственной специализированной нейросети
    - Интеграция с официальными источниками данных (NOTAM)
    - Расширение спектра анализируемых данных
    - Формирование информационной карты популярных площадок запуска и космодромов
    - Разделение функционала ПО на разные лицензии, включая бесплатную для увеличения охвата аудитории

### Statement of Work (SoW): Data Structure Analysis

The environmental and situational data is provided in a JSON format. 
Data is categorized into three temporal layers:
1. **Historical (Archive):** Historical trends within a window of [HISTORY_WINDOW_YEARS] years.
2. **Real-time (Now):** Data captured at the 'request_time'.
3. **Predicted (PR):** Calculated/propagated values for the specific 'target_timestamp' (launch date).

#### JSON Schema Definition:
{
  "location": {
    "name": "string"               // Geolocation name of the target site.
  },
  "wind_profile_now": [            // Vertical wind scan at request time.
    [Altitude(m), Speed(m/s), Direction(deg), Temp(C)] 
  ],
  "aqi_now": {                     // Air Quality Index (AQI) at request time.
    "pm2_5": float, "pm10": float, "no2": float, "so2": float, "o3": float, "co": float 
  },
  "aqi_trends": [                  // Historical AQI data for the same calendar date in previous years.
    {"date": "ISO8601", "content": { ... }}
  ],
  "weather_summary": {
    "pressure_surface": float,     // Surface pressure in hPa (request time).
    "average_humidity": int,       // Average humidity percentage (%) (request time).
    "cloud_cover": int,            // Total cloud cover percentage (%) (request time).
    "visibility": int,             // Meteorological visibility in meters (request time).
    "forecast_7d": [int],          // 7-day weather forecast starting from request time (WMO weather codes).
    "weather_normal": {            // Climate normals (averages) for this location and date over A-years.
        "temp_norm": float, "cloud_norm": float, "pressure_norm": float
    }
  },
  "space_environment": {
    "kp_index_now": int,           // Planetary K-index (geomagnetic activity) at request time.
    "xray_flux_now": "string",     // Solar X-ray flare class (e.g., "M2.8") at request time.
    "donki_trends": [              // Solar activity history (CME/Flares) for [HISTORY_WINDOW_YEARS].
        {"year": int, "flare_count": int, "peak_class": "string"}
    ],
    "mag_declination_pr": float,   // Calculated magnetic declination for the target launch date.
    "sun_pos_pr": [az, el],        // Predicted Sun position at launch time [Azimuth, Elevation].
    "moon_pos_pr": [az, el],       // Predicted Moon position at launch time [Azimuth, Elevation].
    "objects_predicted": [         // Satellite/Debris orbital data propagated to the launch date.
        {"name": "string", "is_visible": bool, "position_prediction": { ... }}
    ]
  },
  "surface": {
    "height_msl": float,           // Elevation above Mean Sea Level (meters).
    "slope_degree": float,         // Surface slope gradient (degrees).
    "terrain_type": "string"       // Surface classification (e.g., "Flat Plain", "Mountainous").
  },
  "aviation": {
    "shedules_now": [              // Active aircraft within the proximity radius at request time.
        {"callsign": "string", "altitude_m": float, "velocity_ms": float, "on_ground": bool}
    ]
  }
}
